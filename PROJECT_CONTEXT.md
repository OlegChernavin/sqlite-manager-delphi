## Контекст проекта для агентов

- **Тип проекта**: настольное приложение для редактирования/управления базами данных **SQLite3**
- **Язык**: **Object Pascal (Delphi)**
- **IDE / компилятор**: **Delphi 10.4 (Sydney)**  
  > Если в `README.md` указана другая версия Delphi, приоритетной считается именно эта информация.
- **Фреймворк UI**: **VCL, Windows‑only**
- **Целевая ОС**: **Windows 10+ (32‑/64‑bit)**

### Работа с БД

- **СУБД**: SQLite 3
- **Доступ**: через **`sqlite3.dll`** и обёртку на Delphi (`SQLite3.pas` / аналогичный модуль)
- **Подключение**: файловые БД `.sqlite`, `.db` и т.п., без клиент‑серверной части
- **Нет ORM**: используется низко/среднеуровневая обёртка поверх C‑API SQLite

### Структура приложения (в общих чертах)

- **`SQLiteManager.dpr`**: главный проект, точка входа
- **Главная форма**: дерево объектов БД (таблицы, индексы, триггеры и т.д.), вкладки с данными, SQL‑редактор
- **Модуль работы с БД**: единая точка для:
  - открытия/закрытия соединения с файлом БД,
  - выполнения SQL‑запросов (DDL/DML),
  - импорта/экспорта (CSV, SQL, XML и пр.),
  - транзакций.

### Что важно учитывать агентам

- **Сохранить поддержку Delphi 10.4**: не использовать конструкции/фичи, появившиеся только в поздних версиях Delphi.
- **SQLite‑специфика**:
  - транзакции, блокировки (`database is locked`) и `busy_timeout`;
  - совместимость с `sqlite3.dll` в поставке проекта.
- **UI‑код**: логика часто завязана на события VCL‑компонентов (формы, гриды, меню); изменения в бизнес‑логике могут требовать синхронизации с обработчиками событий.
- **Файловая БД**: операции с путями/файлами (открытие, последние файлы, ini‑настройки) критичны для UX.
