# AI Integration for SQLite Manager

## Обзор

Интеграция AI-функций для редактирования и выполнения SQL-запросов в Delphi-версии SQLite Manager.

## Возможности

### 1. **Форматирование SQL** (Format SQL)
- Автоматическое форматирование SQL-запросов
- Правильные отступы и переносы строк
- Upper-case для ключевых слов

### 2. **Объяснение запросов** (Explain Query)
- AI объясняет, что делает SQL-запрос
- Разбор сложных JOIN, подзапросов, функций
- Подходит для изучения и документирования

### 3. **Оптимизация SQL** (Optimize SQL)
- Анализ производительности запроса
- Рекомендации по индексам
- Предложения по переписыванию запроса

### 4. **Генерация SQL** (Generate SQL)
- Создание запросов по текстовому описанию
- Пример: "найти всех пользователей с заказами за последний месяц"

## Настройка

### Быстрый старт

1. **Tools → AI Settings...** (или правый клик в редакторе SQL → AI Tools → AI Settings)

2. **Выберите провайдер** из списка:

   | Сервис | Тип | Бесплатный тариф | Скорость |
   |--------|-----|------------------|----------|
   | **Groq** | OpenAI-совместимый | ✅ Да (ограниченно) | ⚡ Очень быстро |
   | **OpenRouter** | Агрегатор | ✅ Есть бесплатные модели | Средняя |
   | **OpenAI** | OpenAI | ❌ Платный | Быстро |
   | **DeepSeek** | OpenAI | ✅ Щедрый бесплатный | Быстро |
   | **Ollama (Local)** | Локально | ✅ Полностью бесплатно | Зависит от ПК |
   | **LM Studio** | Локально | ✅ Полностью бесплатно | Зависит от ПК |

3. **Получите API ключ**:
   - Нажмите кнопку **"Get API Key"**
   - Откроется сайт провайдера
   - Зарегистрируйтесь и создайте ключ
   - Вставьте ключ в поле **API Key**

4. **Нажмите "Test Connection"** для проверки

5. **Сохраните настройки**

### Рекомендуемые сервисы

#### Для начала (бесплатно):

**1. Groq** (рекомендуется)
- Сайт: https://console.groq.com/keys
- Модель: `llama-3.3-70b-versatile`
- Плюсы: Очень быстро, бесплатно с лимитами
- Минусы: Лимит ~30 запросов/час

**2. DeepSeek**
- Сайт: https://platform.deepseek.com/api_keys
- Модель: `deepseek-chat`
- Плюсы: Хороша для кода, дешёвая
- Минусы: Китайский сервис

**3. OpenRouter** (доступ к многим моделям)
- Сайт: https://openrouter.ai/keys
- Модель: `openai/gpt-4o-mini` или `meta-llama/llama-3-70b-instruct`
- Плюсы: Один ключ для 100+ моделей
- Минусы: Платно, но дёшево

#### Для локального использования (полностью бесплатно):

**Ollama**
1. Установите: https://ollama.ai
2. Скачайте модель: `ollama pull llama3.2` или `ollama pull sqlcoder`
3. В настройках выберите "Ollama (Local)"
4. API Key можно не указывать

**LM Studio**
1. Установите: https://lmstudio.ai
2. Скачайте любую GGUF модель
3. Запустите локальный сервер
4. В настройках выберите "LM Studio (Local)"

## Использование

### Контекстное меню редактора SQL

Правый клик в поле SQL-запроса:

```
AI Tools
├── Format SQL      (Ctrl+не назначено)
├── Explain Query
├── Optimize SQL
├── Generate SQL...
└── AI Settings...
```

### Горячие клавиши

По умолчанию не назначены. Можно настроить в Delphi IDE или через Windows.

### Примеры использования

#### Форматирование

**До:**
```sql
select id,name,email from users where status='active' order by created_at desc
```

**После Format SQL:**
```sql
SELECT id, name, email
FROM users
WHERE status = 'active'
ORDER BY created_at DESC
```

#### Объяснение запроса

Введите сложный запрос → AI Tools → Explain Query

Получите подробное объяснение:
- Какие таблицы участвуют
- Типы JOIN
- Условия фильтрации
- Сортировка и группировка

#### Генерация запроса

AI Tools → Generate SQL...

Описание: "показать топ-5 пользователей по сумме заказов за 2024 год"

AI создаст SQL-запрос автоматически.

## Настройки

### Параметры AI

| Параметр | Значение по умолчанию | Описание |
|----------|----------------------|----------|
| **Timeout** | 30000 мс | Таймаут запроса к API |
| **Max Tokens** | 1024 | Макс. длина ответа |
| **Temperature** | 0.3 | Креативность (0-1, для SQL лучше 0.1-0.3) |

### Хранение настроек

Настройки сохраняются в файле `SQLiteManager.ini`:

```ini
[AI]
Provider=OpenAI
ProviderName=Groq
APIKey=sk-...
Endpoint=https://api.groq.com/openai/v1/chat/completions
Model=llama-3.3-70b-versatile
Timeout=30000
MaxTokens=1024
Temperature=0.3
Enabled=1
```

## Решение проблем

### "AI features are not configured"
- Откройте AI Settings
- Включите "Enable AI Features"
- Укажите API Key (для облачных сервисов)
- Нажмите "Test Connection"

### "Connection failed"
- Проверьте интернет-соединение
- Убедитесь, что Endpoint правильный
- Проверьте API Key
- Увеличьте Timeout

### Для локальных моделей (Ollama, LM Studio):
- Убедитесь, что сервер запущен
- Проверьте порт (Ollama: 11434, LM Studio: 1234)
- Убедитесь, что модель загружена

### Медленные ответы
- Попробуйте Groq (очень быстро)
- Уменьшите Max Tokens
- Для локальных: используйте меньшую модель

## Безопасность

⚠ **Важно:**
- API ключи хранятся в локальном файле `.ini`
- Не передавайте файл `SQLiteManager.ini` другим
- Для локальных моделей ключи не требуются
- SQL-запросы отправляются на сервер провайдера

## Лицензия

Интеграция использует стандартные HTTP-запросы к публичным API.
Убедитесь, что вы соблюдаете условия использования выбранного провайдера.

## Поддержка

При возникновении проблем:
1. Проверьте лог (будет добавлен в будущих версиях)
2. Попробуйте другой API endpoint
3. Убедитесь, что Indy (HTTP-библиотека) обновлён
