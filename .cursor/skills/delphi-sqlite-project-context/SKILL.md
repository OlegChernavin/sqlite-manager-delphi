# Delphi SQLite Project Context

## When to use this skill

Use this skill **whenever the agent is operating inside this repository** and needs to:

- Understand the **технологический стек** (Delphi 10.4, VCL, SQLite3).
- Понять **общую архитектуру** приложения (главная форма, модуль работы с БД, обёртка над `sqlite3.dll`).
- Найти, **какие файлы читать в первую очередь** для получения контекста.

## Обязательные шаги и порядок действий

Когда ты (агент) начинаешь работать в этом репозитории:

1. **Сначала прочитай краткий контекст проекта**:
   - Прочитай файл `PROJECT_CONTEXT.md` в корне репозитория.
   - Извлеки оттуда:
     - версию Delphi, на которую нужно ориентироваться;
     - тип UI (VCL);
     - информацию о работе с SQLite (через `sqlite3.dll` и Delphi-обёртку);
     - краткое описание структуры приложения.

2. **Затем при необходимости прочитай подробный README**:
   - Прочитай `README.md` в корне проекта, если:
     - тебе нужен **детализированный обзор возможностей** приложения;
     - нужно понять **структуру файлов** и модули (например, `SQLite3.pas`, `DBModule.pas`, `MainForm.pas`);
     - требуются сведения о **настройках, сборке, установщике**.

3. **Фиксируй ключевые ограничения стека** и соблюдай их в дальнейшем:
   - Используй **Delphi 10.4 (Sydney)** как базовый таргет:
     - не применяй фичи, доступные только в более поздних версиях Delphi;
     - учитывай, что UI построен на **VCL** и ориентирован на **Windows 10+**.
   - Помни, что БД — это **SQLite 3**:
     - подключение через `sqlite3.dll`;
     - важно учитывать блокировки (`database is locked`), транзакции и `busy_timeout`.

4. **При изменениях кода**:
   - Убедись, что изменения совместимы с:
     - версией Delphi из `PROJECT_CONTEXT.md`;
     - архитектурой, описанной в `README.md`.
   - Если изменения затрагивают:
     - модуль работы с БД;
     - формы, связанные с SQL/структурой БД;
     - логику импорта/экспорта;
     - **обязательно** сверяйся с описанием архитектуры в README и текущим кодом соответствующих модулей.

## Краткое резюме для быстрого старта

- **Главные файлы контекста**:
  - `PROJECT_CONTEXT.md` — краткий, специально для агентов (стек и общая архитектура).
  - `README.md` — подробное описание проекта, возможностей, структуры и сборки.
- **Стек**:
  - Delphi 10.4 (Sydney), VCL, Windows 10+, SQLite3 через `sqlite3.dll`.
- **Рекомендация для агента**:
  - Перед любыми нетривиальными изменениями **перечитывай хотя бы `PROJECT_CONTEXT.md`**, чтобы не нарушить принятые ограничения.
