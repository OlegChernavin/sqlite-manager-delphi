# Участие в проекте

Спасибо за интерес к **SQLite Manager for Delphi**.

## Как начать

1. Форкните репозиторий на GitHub.
2. Клонируйте свой форк и создайте ветку от `main`.
3. Установите [Delphi 10.4+](README.md#требования), **SynEdit** и **sqlite3.dll** (см. [THIRD_PARTY.md](THIRD_PARTY.md)).
4. Соберите `SQLiteManager.dproj` в конфигурации Debug/Release.

## Pull Request

- Один PR — одна логическая задача (фича или исправление).
- Не коммитьте артефакты сборки (`*.dcu`, `Win32/`, `*.exe`, `sqlite3.dll`, `__history/`).
- Кратко опишите **что** и **зачем** изменено.
- Для UI-изменений приложите скриншот, если уместно.

## Сообщения об ошибках

Используйте [шаблон Issue](.github/ISSUE_TEMPLATE/bug_report.yml) на GitHub: версия Windows, версия Delphi, шаги воспроизведения, ожидаемое и фактическое поведение.

## Стиль кода

- Следуйте существующему стилю в `.pas` / `.dfm` файлах.
- Не поднимайте минимальную версию Delphi без обсуждения в Issue.
- Бизнес-логика БД — в `DBModule.pas`; UI — в формах.
